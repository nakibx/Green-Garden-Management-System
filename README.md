# Green-Garden-Management-System

A database management system designed to simplify restaurant operations and event bookings for Green Garden.

## Features
- Food Order Management
- Menu Management
- Event Space Booking
- User Management
- Branch Management
- Cash & Card Payment Support
- Admin Reports

## Technologies
- MySQL
- SQL
- Database Management System (DBMS)

## Database Tables
Users, Orders, FoodItems, Bookings, Branches, and Floors.
